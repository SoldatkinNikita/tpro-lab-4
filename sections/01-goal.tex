\section{Цель работы}

Изучить унифицированный процесс разработки программного обеспечения RUP,
приобрести умения построения модели требований и ознакомиться с построением
модели требований с помощью PlantUML.

\section{Задание}

Для подсистемы анализа и поиска музыкальных произведений с помощью ИИ
необходимо выполнить следующие действия [1]:
\begin{enumerate}
  \item Создать проект модели UML.
  \item Описать исходные функциональные и нефункциональные требования,
  построить диаграмму прецедентов с актёрами и связями.
  \item Составить спецификации основных прецедентов и диаграммы деятельности.
  \item Уточнить диаграмму прецедентов, используя отношения включения
  и расширения и точки расширения.
  \item Построить модель классов предметной области.
  \item Составить прототип пользовательского интерфейса на основе
  прецедентов и модели предметной области.
\end{enumerate}
